# Contributing

Use a small pull request with a concrete description and validation. Run all checks listed in README. UI / player changes also need testing with a TV remote: arrows, OK, Back, visible focus and real text inputs.

Keep Russian and English UI strings in sync. Preserve third-party attribution and license headers. Keep debugging disabled in ordinary Release builds. Do not add private history, device addresses, signing keys, signed stream URLs or account data to issues or commits.

Suggested Android TV checks: initial empty favorites / cursor mode, address editor, tab restore, history pagination and retention, video discovery, player controls, exit cancellation and confirmation.

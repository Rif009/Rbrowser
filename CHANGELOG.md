# Changelog

## 0.8.2

- Register Rbrowser for the standard Android browser shortcut. Manufacturer-specific WEB buttons may use their own launcher.
- Add Russian and English installation guides.

## 0.8.1

- Add an animated splash screen, a lavender video indicator, and a repository link.
- Add Android's default browser selection and support for incoming HTTP and HTTPS links.

## 0.8.0

- Cursor mode and empty favorites on fresh installs; unchanged legacy starter bookmarks are removed once.
- A non-interactive video-found notification with remote instructions and automatic dismissal.
- Native-player exit confirmation, with Continue focused by default; cancel restores previous playback state.
- Source distribution prepared for GitHub with MIT licensing for original code, retained third-party notices and checks / manual APK workflow.

## 0.7.0

- Fixed unintended input focus / keyboard / scrolling during Vost episode clicks and toolbar collapse.
- Current blob/MSE frame media takes priority over previous episode requests.
- Configurable 7 / 30 / 90 / 365-day history retention; 30-day default and 50-row pages.

## 0.6.1

- Indigo circular R icon, matching home mark and TV banner.

## 0.6.0

- Fixed direct voice search; added system / Russian / English language choice.
- Video discovery moved to the second toolbar position with green stream indication.
- Improved native Media3 remote focus, speed, audio and seeking controls.
